# VocaSales demo

[Open the interactive prototype](https://ddigreen.github.io/vocasales-demo/)

A static sales analytics UI demonstration using synthetic CRM records and authored call transcripts. The left navigation can be collapsed on desktop and opens as a drawer on mobile. No installation, login, real audio, backend or model inference is needed. Edits reset when the page reloads.

This repository contains only the public demo. Research reports and team planning materials remain in the private project repository.
